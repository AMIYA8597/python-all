│   │   │   ### 1. Introduction to Python
│   │   │   Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum in 1991. It emphasizes readability, simplicity, and versatility. Key features: dynamic typing, garbage collection, extensive standard library, and support for multiple paradigms (procedural, OOP, functional).
│   │   │   
│   │   │   #### History and Evolution
│   │   │   - 1991: Python 0.9.0 released.
│   │   │   - 2000: Python 2.0 (with garbage collection).
│   │   │   - 2008: Python 3.0 (breaking changes for Unicode, etc.).
│   │   │   - Versions: Python 3.6 (f-strings), 3.8 (walrus operator), 3.9 (type hints), 3.10 (pattern matching), 3.11 (faster runtime), 3.12 (improved errors).
│   │   │   Why Python? Easy to learn, vast ecosystem (e.g., for AI/ML), cross-platform.
│   │   │   
│   │   │   ### 2. Basic Syntax and Structure
│   │   │   A basic Python program:
│   │   │   ```
│   │   │   print("Hello, World!")
│   │   │   ```
│   │   │   - No semicolons; indentation defines blocks.
│   │   │   - Shebang: #!/usr/bin/env python3 for scripts.
│   │   │   - Modules: import math.
│   │   │   
│   │   │   ### 3. Variables and Data Types
│   │   │   - Dynamic typing: x = 5 (int), y = 3.14 (float), z = "Hello" (str), b = True (bool).
│   │   │   - Collections: list [1,2,3], tuple (1,2,3), set {1,2,3}, dict {'a':1}.
│   │   │   - NoneType: None (null equivalent).
│   │   │   Memory Model (Conceptual Diagram in ASCII):
│   │   │   ```
│   │   │   Python Heap (Garbage Collected):
│   │   │   +-----------------+
│   │   │   | int x = 5      |  <- Immutable, reference-counted
│   │   │   +-----------------+
│   │   │   | float y = 3.14 |  <- Immutable
│   │   │   +-----------------+
│   │   │   | list l = [1,2] |  <- Mutable, references to objects
│   │   │   +-----------------+
│   │   │   ```
│   │   │   - Constants: Conventionally uppercase, e.g., MAX = 100 (not enforced).
│   │   │   Step-by-Step Learning: Start with type(x) to inspect, id(x) for memory address.
│   │   │   
│   │   │   ### 4. Operators and Expressions
│   │   │   - Arithmetic: +, -, *, /, // (floor div), % (mod), ** (power).
│   │   │   - Relational: ==, !=, >, <, >=, <=.
│   │   │   - Logical: and, or, not.
│   │   │   - Bitwise: &, |, ^, ~, <<, >>.
│   │   │   - Assignment: =, +=, etc.
│   │   │   Precedence: Parentheses > Exponent > Unary > Multiplicative > Additive > Relational > Logical.
│   │   │   Example: (5 + 3) * 2 == 16.
│   │   │   
│   │   │   ### 5. Control Structures
│   │   │   - If-elif-else: if x > 0: ...
│   │   │   - Loops: for i in range(5): ..., while x < 10: ...
│   │   │   - Break, continue, pass.
│   │   │   - Comprehensions: [x**2 for x in range(5)] (list comp).
│   │   │   
│   │   │   ### 6. Functions
│   │   │   - Definition: def add(a, b=0): return a + b
│   │   │   - Args: Positional, keyword, *args (var args), **kwargs (var kwargs).
│   │   │   - Lambda: lambda x: x*2
│   │   │   - Decorators: @decorator def func(): ...
│   │   │   
│   │   │   ### 7. Lists, Tuples, Sets, Dicts
│   │   │   - List: Mutable, indexed, l.append(4)
│   │   │   - Tuple: Immutable, t = (1,2)
│   │   │   - Set: Unordered unique, s.add(3)
│   │   │   - Dict: Key-value, d['key'] = value
│   │   │   Operations: Slicing l[1:3], membership 'a' in d.
│   │   │   
│   │   │   ### 8. Strings
│   │   │   - Immutable: s = "Hello", s.upper()
│   │   │   - Formatting: f"{x=5}", "Hello {}".format(name)
│   │   │   - Operations: split, join, find, replace.
│   │   │   
│   │   │   ### 9. OOP Basics
│   │   │   - Class: class Person: def __init__(self, name): self.name = name
│   │   │   - Inheritance: class Student(Person): ...
│   │   │   - Methods: Instance, class (@classmethod), static (@staticmethod).
│   │   │   
│   │   │   ### 10. File Handling
│   │   │   - with open('file.txt', 'r') as f: content = f.read()
│   │   │   - Modes: r, w, a, b (binary).
│   │   │   
│   │   │   ### 11. Exceptions
│   │   │   - try: ... except ValueError: ... else: ... finally: ...
│   │   │   - Raise: raise Exception("Msg")
│   │   │
