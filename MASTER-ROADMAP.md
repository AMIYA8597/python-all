# Master Chronological Roadmap

This roadmap provides a structured, chronological path from zero to Generative AI Engineer. It is designed to take roughly 6-9 months of consistent effort (15-20 hours/week).

## Phase 1: Core Python Mastery (Weeks 1-4)
*Goal: Write clean, idiomatic Python code.*
*   **Week 1: Basics & Data Types**: Variables, Strings, Lists, Dictionaries, Control Flow.
*   **Week 2: Functions & OOP**: Functions, Scope, Classes, Inheritance, Polymorphism, Magic Methods.
*   **Week 3: Advanced Concepts**: List/Dict Comprehensions, Generators, Decorators, Context Managers, Error Handling.
*   **Week 4: Environment & Testing**: Git, Virtual Environments (venv/conda), Pytest, basic file I/O.
*   *Milestone*: Complete the "CLI Password Manager" and "Matrix Operations Library".

## Phase 2: Data Structures & Algorithms (Weeks 5-12)
*Goal: Pass technical interviews and optimize code.*
*   **Week 5: Big O & Arrays**: Time/Space complexity, Array manipulation, Two Pointers, Sliding Window.
*   **Week 6: Linked Lists & Stacks/Queues**: Implementation, Reversal, Cycle Detection.
*   **Week 7: Hashing & Strings**: Hash Maps, Hash Sets, String manipulation, Anagrams.
*   **Week 8: Trees (Binary & BST)**: Traversals (BFS/DFS), finding depths, BST properties.
*   **Week 9: Graphs**: Representations (Adjacency List/Matrix), Graph Traversals, Topological Sort.
*   **Week 10: Heaps & Priority Queues**: Min/Max Heaps, Top K problems.
*   **Week 11: Dynamic Programming (Part 1)**: Memoization, Tabulation, 1D DP (Climbing Stairs).
*   **Week 12: Dynamic Programming (Part 2) & Backtracking**: 2D DP, Subsets, Permutations.
*   *Milestone*: Solve 50+ LeetCode Mediums covering all patterns.

## Phase 3: Data Science & ML Foundations (Weeks 13-18)
*Goal: Train classical ML models and understand the math.*
*   **Week 13: Data Manipulation**: NumPy (Arrays, Broadcasting), Pandas (DataFrames, GroupBy, Merging).
*   **Week 14: EDA & Visualization**: Matplotlib, Seaborn, handling missing values, identifying outliers.
*   **Week 15: Math for ML**: Linear Algebra basics, Derivatives (Gradient), Probability distributions.
*   **Week 16: Supervised Learning (Regression)**: Linear Regression, Cost Functions, Gradient Descent.
*   **Week 17: Supervised Learning (Classification)**: Logistic Regression, Decision Trees, Random Forests, Metrics (ROC/AUC).
*   **Week 18: Unsupervised & Deployment**: K-Means Clustering, PCA, Intro to FastAPI to serve a model.
*   *Milestone*: Complete the "Customer Churn Predictor" project.

## Phase 4: Deep Learning Foundations (Weeks 19-24)
*Goal: Understand Neural Networks and PyTorch.*
*   **Week 19: Intro to Neural Nets**: Perceptrons, Activation Functions, Forward/Backward propagation.
*   **Week 20: PyTorch Basics**: Tensors, Autograd, building custom DataLoaders.
*   **Week 21: Computer Vision (CNNs)**: Convolutions, Pooling, ResNet architectures.
*   **Week 22: Sequence Models (RNN/LSTM)**: Handling sequential data, Time Series.
*   **Week 23: Intro to NLP**: Tokenization, Word2Vec, TF-IDF.
*   **Week 24: MLOps Basics**: MLflow for tracking experiments, Dockerizing a PyTorch model.
*   *Milestone*: Complete the "Custom Image Classifier" project.

## Phase 5: Generative AI & LLMs (Weeks 25-32)
*Goal: Build agentic workflows and RAG systems.*
*   **Week 25: The Transformer Architecture**: Attention Mechanism, Encoder vs. Decoder models.
*   **Week 26: Hugging Face Ecosystem**: `transformers` library, downloading models, pipelines.
*   **Week 27: Prompt Engineering & API usage**: OpenAI API, advanced prompting (Few-Shot, CoT).
*   **Week 28: Retrieval-Augmented Generation (RAG)**: Vector Databases (Chroma/Pinecone), Embeddings, LangChain/LlamaIndex.
*   **Week 29: Advanced RAG**: Semantic chunking, Query rewriting, Re-ranking.
*   **Week 30: Fine-Tuning**: PEFT, LoRA, QLoRA using Hugging Face `trl`.
*   **Week 31: Agentic Workflows**: Building agents with tools, LangGraph, AutoGen.
*   **Week 32: Deployment & Optimization**: vLLM, GGUF quantization, prompt injection security.
*   *Milestone*: Complete the "Chat-with-your-Codebase" RAG project.
