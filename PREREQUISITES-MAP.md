# MASTER PREREQUISITES MAP

This document maps the exact prerequisite knowledge required before starting any advanced topic in the repository. Do NOT skip prerequisites.

## 1. Python Programming Prerequisites
**Target:** Intermediate Python Engineering
- **Required Before Start:**
  - Variables and Objects (References)
  - Control Flow (if, loops)
  - Functions, Scope (LEGB)
  - Basic Data Structures (list, dict, set, tuple)

**Target:** Advanced Python (Concurrency, Metaclasses)
- **Required Before Start:**
  - Object-Oriented Programming (Classes, Inheritance, MRO)
  - Memory Model (Garbage Collection, Reference Counting)
  - Iterators and Generators

## 2. Data Structures & Algorithms (DSA)
**Target:** Algorithmic Problem Solving
- **Required Before Start:**
  - Python Fundamentals
  - Big-O Complexity Analysis
  - Recursion
  - Memory management concepts (Pointers/References)

## 3. Mathematics for AI
**Target:** Machine Learning & Deep Learning
- **Required Before Start:**
  - **Linear Algebra:** Vectors, Matrices, Dot Products, Eigenvalues.
  - **Calculus:** Derivatives, Partial Derivatives, Chain Rule, Gradients.
  - **Probability:** Distributions, Bayes' Theorem.
  - **Statistics:** Mean, Variance, Hypothesis Testing.

## 4. Machine Learning
**Target:** Classical ML (Regression, Trees, SVM)
- **Required Before Start:**
  - Python Data Stack (NumPy, Pandas, Scikit-Learn)
  - Linear Algebra (Vector math)
  - Calculus (Optimization/Gradients)
  - Statistics (Evaluation metrics)

## 5. Deep Learning & Neural Networks
**Target:** PyTorch & Deep Learning
- **Required Before Start:**
  - Classical Machine Learning concepts (Overfitting, Loss, Validation)
  - Calculus (Chain Rule for Backpropagation)
  - Linear Algebra (Matrix Multiplication for Layer weights)

## 6. Generative AI & LLMs
**Target:** Transformers & LLM Architecture
- **Required Before Start:**
  - Deep Learning (Sequence models)
  - PyTorch fundamentals
  - Mathematics (Softmax, Matrices)

**Target:** RAG & Vector Search
- **Required Before Start:**
  - Linear Algebra (Cosine Similarity, Vectors)
  - LLM API Usage
  - Basic Data Engineering (Chunking, Parsing)

## 7. Agentic AI
**Target:** AI Agents & Workflows
- **Required Before Start:**
  - Prompt Engineering (Structured Outputs)
  - Python Software Engineering (APIs, Error Handling)
  - State Machines & Graph Theory Concepts

## 8. MLOps & Production
**Target:** AI System Deployment
- **Required Before Start:**
  - Agentic/AI workflows
  - Software Engineering (Docker, Git, CI/CD)
  - Testing & Debugging
