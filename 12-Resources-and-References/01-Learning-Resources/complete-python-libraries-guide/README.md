## 💻 Installation

### Option 1: Install All Libraries (Recommended)

**Windows:**
```batch
install_libraries.bat
```

**Unix/Linux/macOS:**
```bash
chmod +x install_libraries.sh
./install_libraries.sh
```

### Option 2: Install by Category

**Core Data Science:**
```bash
pip install numpy pandas matplotlib
```

**Machine Learning:**
```bash
pip install scikit-learn xgboost lightgbm
```

**Deep Learning:**
```bash
pip install tensorflow torch torchvision
```

**Computer Vision:**
```bash
pip install opencv-python Pillow scikit-image
```

**NLP:**
```bash
pip install nltk spacy transformers
```

### Option 3: Individual Library Installation
Each library card in the documentation shows the exact installation command.

## 📄 Creating PDF

### Method 1: Browser Print (Recommended)
1. Open `complete-python-libraries-guide.html` in Chrome/Firefox
2. Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
3. Select "Print to PDF" as destination
4. Choose A4 paper size
5. Enable "Background graphics"
6. Save as "Complete-Python-Libraries-Guide.pdf"

### Method 2: Online Tools
1. Upload HTML file to online HTML-to-PDF converter
2. Download generated PDF
3. Popular tools: SmallPDF, ILovePDF, PDF24

### Method 3: Command Line (Advanced)
```bash
# Install wkhtmltopdf
# Ubuntu/Debian: sudo apt-get install wkhtmltopdf
# macOS: brew install wkhtmltopdf
# Windows: Download from wkhtmltopdf.org

wkhtmltopdf complete-python-libraries-guide.html Complete-Python-Libraries-Guide.pdf
```
