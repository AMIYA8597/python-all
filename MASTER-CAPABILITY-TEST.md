# Master Capability Test

This is a comprehensive self-assessment checklist. Use this to gauge your true mastery of the curriculum. If you can confidently answer "Yes" and explain the concept out loud to a rubber duck, check the box.

## Part 1: Python Core

- [ ] Can you explain the difference between `is` and `==`?
- [ ] Do you understand how Python handles memory management and garbage collection (reference counting vs. generational GC)?
- [ ] Can you write a decorator from scratch, including one that takes arguments?
- [ ] Can you explain the Global Interpreter Lock (GIL) and how it affects multithreading in Python?
- [ ] Do you know when to use multithreading vs. multiprocessing vs. asyncio?
- [ ] Can you explain the difference between a generator and a normal function, and when to use `yield`?
- [ ] Can you implement context managers using classes (`__enter__`, `__exit__`) and `contextlib`?
- [ ] Do you understand the Method Resolution Order (MRO) and `super()` in multiple inheritance?
- [ ] Can you explain what a metaclass is and provide a practical use case?
- [ ] Do you know the difference between shallow copy and deep copy?

## Part 2: Data Structures & Algorithms

- [ ] Can you analyze the time and space complexity (Big O) of a given snippet of code?
- [ ] Can you implement a Hash Table from scratch, handling collisions?
- [ ] Can you traverse a Binary Tree using In-order, Pre-order, Post-order, and Level-order traversal?
- [ ] Can you explain the difference between a Graph and a Tree?
- [ ] Can you implement BFS and DFS on a Graph?
- [ ] Can you recognize when a problem requires Dynamic Programming (Overlapping Subproblems + Optimal Substructure)?
- [ ] Can you explain the difference between Top-Down (Memoization) and Bottom-Up (Tabulation) DP?
- [ ] Do you know how to use the Two-Pointer technique?
- [ ] Can you explain and implement QuickSort and MergeSort?
- [ ] Can you explain the properties of a Min-Heap/Max-Heap and when to use them?

## Part 3: Data Science & Machine Learning

- [ ] Can you perform complex GroupBy operations and Aggregations in Pandas?
- [ ] Can you handle missing data (imputation strategies) in a dataset?
- [ ] Can you explain the Bias-Variance Tradeoff and how it relates to model complexity?
- [ ] Can you describe the difference between L1 (Lasso) and L2 (Ridge) regularization?
- [ ] Can you explain how a Decision Tree splits nodes (Gini Impurity, Information Gain)?
- [ ] Can you explain how a Random Forest reduces variance?
- [ ] Can you articulate the difference between Precision, Recall, and F1-Score, and when to optimize for each?
- [ ] Can you explain how Gradient Descent works?
- [ ] Do you know how to set up a robust Cross-Validation pipeline?
- [ ] Can you explain the kernel trick in Support Vector Machines?

## Part 4: Deep Learning & Generative AI

- [ ] Can you explain the vanishing gradient problem and how LSTMs/ReLUs help solve it?
- [ ] Can you describe the role of convolutional layers and pooling layers in a CNN?
- [ ] Can you explain the fundamental innovation of the Transformer architecture (Self-Attention)?
- [ ] Can you describe the difference between Encoder-only (BERT), Decoder-only (GPT), and Encoder-Decoder (T5) architectures?
- [ ] Can you explain how word embeddings (Word2Vec) differ from contextual embeddings?
- [ ] Can you map out the end-to-end architecture of a Retrieval-Augmented Generation (RAG) pipeline?
- [ ] Do you know how to implement chunking strategies for vector databases?
- [ ] Can you explain the difference between pre-training, supervised fine-tuning (SFT), and RLHF?
- [ ] Can you describe PEFT techniques like LoRA?
- [ ] Can you write effective prompts using few-shot prompting and chain-of-thought (CoT)?

---
**Assessment Rule**: If you cannot answer a question clearly in under 2 minutes, uncheck the box and revisit that section of the repository.
